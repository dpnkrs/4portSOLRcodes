Processing order
----------------
1. Discover Phase II raw standards, switch-term CSVs, and DUTs by band.
2. Load stitched Phase I Open/Short/Load references from the Phase I outputs folder.
3. For each reference pair, extract the active-pair 2x2 submatrix from the measured .s4p.
4. Parse the four wave CSV files for that pair, validate the filename semantics against the active pair, and compute forward/reverse switch ratios using a_over_b.
5. Apply switch correction to the active-pair through and the relevant one-port standard submatrices.
6. Solve an 8-term SOLR model for that pair using the stitched Phase I reflection standards as the downstream references.
7. Correct the active-pair submatrices of the DUT using the pair model, then assemble the corrected 4-port DUT by averaging diagonal estimates and inserting pair-specific off-diagonal terms.
8. Correct the hold-out DIAG structures with the same pair model for validation.
9. Stitch corrected DUT and hold-out outputs across the three bands for reporting.

Important implementation details
-------------------------------
Reciprocal-thru files are treated as active-pair only. The named pair submatrix is used; the remaining 4-port entries are ignored.
The orthogonal ARC measurements are the calibration references. The DIAG measurements from PhaseII DUTs are held out for validation.
No GLOBALWIN references are used in Phase II. Only FINALFIT_*_STITCHED_FINAL.mat from Phase I are used as the standard definitions.
DIAG hold-outs do not have dedicated switch-wave files in the provided dataset; they are corrected with the switch ratios from the corresponding ARC pair solve.
The switch-term loader enforces the pair semantics a_jS_i / b_jS_i for forward and a_iS_j / b_iS_j for reverse before any ratios are formed.
